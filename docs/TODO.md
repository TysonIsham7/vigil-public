# Open follow-ups

- Re-check the emSign ECC Root CA - G3 Chrome root-store removal after Oct 27, 2026. Chrome said the removal ships for Chrome Root Store clients on 2026-10-27 PDT, sooner on Canary and Beta. `packages/intel/data/distrusted-cas.json` keeps that root block-listed until this re-check shows the outcome changed. Do not drop the block on the calendar date alone.
- When PHP publishes fixed version numbers for CVE-2026-115560, replace the informational `PHP_CVE_2026_115560` note with a version comparison. The 23 October 2026 note on php.net says the full advisory ships with the next regular bugfix release. Do not invent a fixed version before that page names one. Until then, `session.upload_progress.enabled=0` is PHP's interim advice for the unusual serialize-handler setup, and Vigil cannot see `php.ini`.
- CVE-2026-115557 (CPython ssl denylist for the compromised eMudhra intermediates, announced 24 October 2026) has no stable fixed release. The CVE record says affected before 3.16.0. python.org lists 3.16 as a pre-release. The newest stable releases are 3.15.1, 3.14.9, and 3.13.17, all dated 21 October 2026, which is before this denylist. Do not compare `python --version` with 3.16.0. When python.org publishes a stable release on a supported line that includes the denylist, add a recommendation-only `vigil doctor` check for that version. Do not treat the 21 October releases as the fix.
- CISA added CVE-2026-110447 (Collabora Online built-in CODE Server, command injection) and CVE-2026-114625 (Arista VeloCloud Orchestrator, SQL injection) to the Known Exploited Vulnerabilities catalog on 23 October 2026. Vigil cannot see those products from a page or a certificate. Do not add a remote version probe. Patch them from the vendor's own instructions.
- CVE-2026-115929 (MongoDB Compass, fixed in 1.53.1) and CVE-2026-108013 (BigFix, Mozilla bundle dated 2026-10-20 or later) are the same eMudhra keys inside a product's private CA bundle. `TRUSTSTORE_EMUDHRA` already reports a bundle Vigil is given. Do not search the disk for Compass or BigFix. Reuse that check only when a path is supplied.
- WordPress plugin records published to NVD on 24 October 2026 are not WordPress core. Leave `WP_FINGERPRINT` informational. Do not add a plugin CVE list.
