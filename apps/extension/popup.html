Vigil

This tab

Normal mode only changes the badge. High Security holds unknown sites until the check finishes.

    Page guards run in Chrome. Each one stays on this machine. Turning a guard off stops it on pages opened after that. A page already open keeps its hook until you reload it.

    Optional fallback when the native host is not running. Paste the token vigil serve prints. Nothing is sent to any other host.

    Vigil is a first-pass filter, not an audit.
